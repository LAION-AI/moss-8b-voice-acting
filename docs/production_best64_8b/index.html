Production best-of-64 — 8B MOSS, top-3 of 64 per emotion

What this is. the production best-of-64 emotion grid (recipe 1b), regenerated with the 8B MOSS-TTS-v1.5 model — it replaces the 4B local transformer used in the original reference run. for each of the 40 EmoNet emotions we sampled 64 diverse prompts from laion/voice-acting-prompts (geminittsprompts-output-en.tar), built a (text, procedural-instruction) pair per the recipe, and generated one group of 64 takes with no reference audio (audio_temperature 0.8, audio_repetition_penalty 1.1, text_temp 0.7, top_p 0.95, top_k 25), batched across GPUs 0-6.

each take is scored on three signals: target emotion = the Empathic-Insight-Voice-Plus head for that group's emotion (BUD-E-Whisper encoder → that emotion's regressor), blend = VoiceCLAP-commercial vocal-burst blend, genu = VoiceCLAP-commercial genuineness. the ranking reward is

reward = w·norm(target emotion) + norm(blend) + norm(genu)  (w = 1.0)

with each of the three signals min-max normalized within each 64-sample group (a per-emotion best-of-N ranking). the 64 takes are ranked descending; the best-of-64 is the top. below: a summary table, then per emotion the instruction template used and the top-3 of 64 (each with its text, target emotion, blend, genu, reward, invWER for context, arousal, rms). players are external 128 kbps mp3 @ 48 kHz.

Voice-Acting Best-of-10 — can sampling 10 takes beat the reference voice?

What is this?

We took 20 reference voice clips (10 German, 10 English) from a large crowd-sourced expressive-speech corpus — each clip carries a distinct emotion (anger, grief, ecstasy, fear, …) and a natural-language voice caption. For every reference we wrote a fresh, emotionally-matched 3-sentence script + delivery instruction, then asked our fine-tuned MOSS-TTS 8 billion-parameter speech model to voice-clone the reference and perform that script 10 times (10 independent takes, varying the random seed). That is 199 generated clips across 20 groups.

Every take — and every original reference — is then scored by two independent VoiceCLAP reward heads: a blend quality head (0–10) and a genuineness head (0–6, “how real / human does this sound”, VoiceCLAP-commercial). Word-error-rate (WER) from Parakeet-tdt-0.6b-v3 gives invWER = max(0, 1−WER) to gate garbled takes.

norm(·) = min–max to [0,1] across all 199 generated clips (blend, genu scaled separately)
combined = invWER × ( norm(genu) + norm(blend) )  ← default ranking
blend×invWER = invWER × blend(raw 0–10)  |  genu×invWER = invWER × genu(raw 0–6)
reference source: a public emotion-attribute reference set model: MOSS-TTS 8B (WITH reference codes) temperature 1.0 · audio rep-penalty 1.1 20 groups × 10 takes = 199 clips gen mean: blend 3.34 · genu 1.48 · invWER 0.91 ref mean: blend 2.89 · genu 1.09

Uplift analysis — best-of-10 vs the original reference

In plain words

The model is cloning each reference voice. The question the boss asked: if we generate 10 takes and keep the best one, can that best take actually sound more genuine and better-blended than the real human reference clip it was copied from? A positive Δ (uplift) means yes — the synthetic best-of-10 out-scores the original on that reward. This matters because it says the reward-guided best-of-N loop is not just imitating the reference, it is improving on it in terms of what these quality/genuineness heads reward.

Best-achievable uplift (below) compares the reference to the single best-scoring take on each axis (the ceiling of what best-of-10 can grab). We also report the combined-reward pick — the one take you would actually ship if you rank by the default combined reward — and how often it beats the reference.
